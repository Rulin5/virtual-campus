# Asset analysis

- Homepage inventory: 218 observed public resources.
- Saved evidence assets: 178 files.
- Game sprites saved locally: 130 files.
- Map-related files: 30 files.
- Map format: Tiled JSON, 140×140 tiles, 16×16 pixels per tile, 24 layers.
- Primary tilesets: 16 `exterior-small*.webp` sheets.
- Character sheets: 384×384 WebP, arranged as 8×8 frames of 48×48 pixels.
- Other types: vehicles, animals, smoke, clouds, waves, particles, UI images,
  portfolio cards, logos and project illustrations.

All runtime assets used by the clone are local. `exterior.png` from the earlier
workspace was an invalid HTML download and is not used. The valid split WebP
tilesets were collected from the public runtime and used to render the map.
