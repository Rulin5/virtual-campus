## Phase 1：对标复刻（预计 2-3 周）

### 目标
1:1 复刻 peteroravec.com，产出纯前端可运行的游戏交互作品集。

### 技术栈
纯 HTML/CSS/JS + Phaser 3 + NES.css，无需构建工具。

### 子任务

#### 1.1 骨架搭建（3 天）

| # | 任务 | 产出 |
|---|------|------|
| 1.1.1 | 创建 `index.html`，包含所有模态窗口 HTML 结构 | 完整 DOM 骨架 |
| 1.1.2 | 引入 NES.css CDN + Google Fonts + Phaser.js | 资源引用就位 |
| 1.1.3 | 编写全局 CSS 样式（自定义光标、滚动条、布局） | `styles.css` |
| 1.1.4 | 实现预加载器（Loading → GIF + 进度条 + 百分比） | 预加载流程 |
| 1.1.5 | 实现 Play 界面（Logo + Play 按钮 + LinkedIn 入口） | 开始界面 |

#### 1.2 游戏核心（5 天）
