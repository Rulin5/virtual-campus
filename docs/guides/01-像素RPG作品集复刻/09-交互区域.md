# 第9章 · 交互区域 (Interaction Zones)

> **Phase 1** — 核心基础搭建 | **预计时间：** 30-40 分钟

---

## 本章目标

- 在地图上定义多个"交互区域"（zone）
- 玩家进入区域时显示提示文字："Press E to enter: [标签]"
- 玩家按 E 键打开对应的模态窗口
- 玩家离开区域时隐藏提示
- 用半透明黄色矩形可视化标记区域位置

---

## 1. 完整代码

以下代码展示了如何定义交互区域、检测玩家进入/离开、显示提示文字、以及响应按键。

### 1.1 在 `create()` 中定义区域和初始化

```javascript
// ===== game.js 的 create() 方法中新增 =====

create() {
  // ... 已有的代码（地图、玩家、NPC、模态管理器）...

  // ==================== 交互区域系统 ====================

  /**
   * 交互区域数据结构
   * 每个 zone 包含：
   * - id        : 唯一标识符
   * - x, y      : 区域中心坐标（世界坐标）
   * - radius    : 触发半径
   * - modalId   : 按 E 后打开的模态窗口 ID
   * - label     : 提示文字显示的标签
   * - color     : 可视化调试矩形的颜色
   */
  this.interactionZones = [
    { id: 'zone-tech',      x: 340, y: 570, radius: 40, modalId: 'tech',      label: 'Tech Stack',      color: 0xffff00 },
    { id: 'zone-about',     x: 520, y: 570, radius: 40, modalId: 'about',     label: 'About Me',        color: 0xffff00 },
    { id: 'zone-cv',        x: 700, y: 570, radius: 40, modalId: 'cv',        label: 'CV / Resume',     color: 0xffff00 },
    { id: 'zone-projects',  x: 900, y: 430, radius: 40, modalId: 'projects',  label: 'Projects',        color: 0xffff00 },
    { id: 'zone-contact',   x: 980, y: 280, radius: 40, modalId: 'contact',   label: 'Contact',         color: 0xffff00 },
    { id: 'zone-memo1',     x: 480, y: 200, radius: 30, modalId: 'memo1',     label: 'Memo #1',         color: 0x00ffff },
    { id: 'zone-memo2',     x: 620, y: 180, radius: 30, modalId: 'memo2',     label: 'Memo #2',         color: 0x00ffff },
    { id: 'zone-memo3',     x: 760, y: 200, radius: 30, modalId: 'memo3',     label: 'Memo #3',         color: 0x00ffff },
    { id: 'zone-memo4',     x: 500, y: 120, radius: 30, modalId: 'memo4',     label: 'Memo #4',         color: 0x00ffff },
    { id: 'zone-memo5',     x: 640, y: 100, radius: 30, modalId: 'memo5',     label: 'Memo #5',         color: 0x00ffff },
    { id: 'zone-memo6',     x: 780, y: 120, radius: 30, modalId: 'memo6',     label: 'Memo #6',         color: 0x00ffff },
    { id: 'zone-bigmap',    x: 200, y: 200, radius: 50, modalId: 'bigmap',    label: 'World Map',       color: 0xff8800 },
    { id: 'zone-underhood', x: 1100,y: 500, radius: 40, modalId: 'underhood', label: 'Under the Hood',   color: 0xff00ff },
  ];

  // ===== 绘制可视化区域标记（半透明矩形） =====
  // 注意：这些矩形仅用于开发调试，正式版本可以隐藏
  this.zoneGraphics = this.add.graphics();
  this.zoneGraphics.setDepth(1);  // 在地面之上，角色之下

  this.interactionZones.forEach(zone => {
    // 绘制半透明黄色矩形
    this.zoneGraphics.fillStyle(zone.color, 0.25);    // 25% 不透明度
    this.zoneGraphics.fillRect(
      zone.x - zone.radius,
      zone.y - zone.radius,
      zone.radius * 2,
      zone.radius * 2
    );
    // 绘制边框
    this.zoneGraphics.lineStyle(2, zone.color, 0.6);
    this.zoneGraphics.strokeRect(
      zone.x - zone.radius,
      zone.y - zone.radius,
      zone.radius * 2,
      zone.radius * 2
    );
  });

  // ===== 提示文字（"Press E to enter: ..."） =====
  // 创建一个 HTML 元素，通过 CSS 定位在画布上方
  this.hintText = document.createElement('div');
  this.hintText.id = 'interaction-hint';
  this.hintText.style.cssText = `
    position: fixed;
    bottom: 80px;
    left: 50%;
    transform: translateX(-50%);
    background: rgba(0, 0, 0, 0.8);
    color: #ffe066;
    font-family: 'Press Start 2P', monospace;
    font-size: 12px;
    padding: 10px 20px;
    border: 2px solid #ffe066;
    border-radius: 4px;
    z-index: 500;
    pointer-events: none;
    display: none;
    text-align: center;
  `;
  document.body.appendChild(this.hintText);

  // 当前正在触发中的区域（用于判断进入/离开）
  this.activeZone = null;

  // ===== 键盘：E 键交互 =====
  this.eKey = this.input.keyboard.addKey(Phaser.Input.Keyboard.KeyCodes.E);

  console.log('[game.js] Interaction zones defined:', this.interactionZones.length);
}
```

### 1.2 在 `update()` 中检测交互

```javascript
// ===== game.js 的 update() 方法中新增 =====

update(time, delta) {
  // ... 已有的代码 ...

  // ==================== 交互区域检测 ====================
  this._updateInteractionZones();
}

// ----- 交互区域检测逻辑（私有辅助方法）-----

_updateInteractionZones() {
  // 如果模态窗口打开中，不处理交互
  if (window.isModalOpen) return;

  const playerX = this.player.x;
  const playerY = this.player.y;

  let foundZone = null;

  // 遍历所有区域，检测玩家是否在某个区域内
  for (const zone of this.interactionZones) {
    const dx = playerX - zone.x;
    const dy = playerY - zone.y;
    const dist = Math.sqrt(dx * dx + dy * dy);

    if (dist <= zone.radius) {
      foundZone = zone;
      break;  // 只触发第一个匹配的区域
    }
  }

  // ===== 状态变化检测 =====

  if (foundZone) {
    if (this.activeZone !== foundZone) {
      // 刚进入新区域
      this.activeZone = foundZone;
      this._showHint('Press E to enter: ' + foundZone.label);
    }

    // 按 E 键打开模态
    if (Phaser.Input.Keyboard.JustDown(this.eKey)) {
      if (window.modalManager) {
        window.modalManager.open(foundZone.modalId);
        this._hideHint();
      }
    }
  } else {
    if (this.activeZone !== null) {
      // 刚离开区域
      this._hideHint();
      this.activeZone = null;
    }
  }
}

// ----- 提示文字操作 -----

_showHint(text) {
  this.hintText.textContent = text;
  this.hintText.style.display = 'block';

  // 添加一个淡入动画效果
  this.hintText.style.opacity = '0';
  this.hintText.style.transition = 'opacity 0.2s ease';
  requestAnimationFrame(() => {
    this.hintText.style.opacity = '1';
  });
}

_hideHint() {
  this.hintText.style.display = 'none';
}
```

## 3. 完整页面效果

交互系统启动后的效果：

1. **场景中** — 半透明彩色方块标记出每个交互区域
2. **走进区域** — 屏幕底部出现像素风格提示：`Press E to enter: Tech Stack`
3. **按下 E 键** — 对应的模态窗口弹出，提示消失
4. **离开区域** — 提示文字消失
5. **模态打开中** — 不再显示新的交互提示

## 5. 验证步骤

1. **运行游戏**，应看到地图上有彩色半透明方块标记
2. **移动玩家走进一个方块**，屏幕底部出现黄色像素风提示文字
3. **按键盘 E 键**，对应的模态窗口弹出
4. **关闭模态**（点 × 或 ESC），提示重新出现（因为玩家仍在区域内）
5. **离开区域**，提示消失
6. **快速在两个区域间切换**，提示文字实时更新
7. **模态打开期间走进其他区域**，不应出现提示（因为 `window.isModalOpen` 为 true）

## 6. 常见坑点

| 问题 | 原因 | 解决方法 |
|------|------|----------|
| 提示文字不显示 | `hintText` 的 z-index 太低被画布遮挡 | 增大 z-index（当前设为 500） |
| 多个区域同时触发 | `break` 只取了第一个；玩家可能站在重叠区 | 如果区域有交叉，缩小 radius 或调整坐标让它们分开 |
| 按 E 无反应 | 键盘未正确绑定，或 `JustDown` 检测不到 | 确保用 `Phaser.Input.Keyboard.JustDown()` 而非 `isDown`（后者会持续触发） |
| 提示闪烁 | update 每帧都在 `_showHint`（重复设置） | 使用 `activeZone` 状态比较避免重复设置 |
| 离开区域后提示仍在 | 距离计算使用了错误的坐标 | 确认 `this.player.x/y` 代表玩家中心位置 |
| 可视化方块遮挡 NPC | `zoneGraphics` 的 depth 太高 | 确保 `setDepth(1)` 低于 NPC 的 depth（本例中 NPC depth 为 9-10） |
| 区域坐标与地图不匹配 | 使用了屏幕坐标而非世界坐标 | 交互区域坐标应该是世界坐标（与 tilemap 坐标系一致） |

## 7. 进阶优化

完成基础系统后，可以进一步改进：

1. **脉冲动画** — 让可视化区域方块有节奏地缩放，更醒目
2. **声音提示** — 走进区域时播放一个小的音效
3. **多键提示** — 某些区域按不同键触发不同行为（如按 E 查看，按 F 拾取）
4. **区域解锁** — 某些区域默认不可见，完成某任务后才激活
5. **动态标签** — 根据游戏状态改变提示文字（如："Show CV" vs "Update CV"）

// 脉冲动画示例（在 create() 中添加）

  repeat: -1,
  ease: 'Sine.easeInOut',
});

## 章节小结

- 交互区域通过 **距离检测** 判断玩家是否靠近
- 提示文字使用 **DOM 元素** 悬浮在画布上方（避免 Canvas 渲染文字性能问题）
- 使用 **状态变量** (`activeZone`) 避免重复渲染提示
- 按 E 键触发 **JustDown** 单次检测，防止连发
- 半透明矩形只用于 **开发调试**，上线后可通过 `zoneGraphics.setVisible(false)` 隐藏
