# 第11章 · 多语言国际化 (i18n Internationalization)

> **Phase 1** — 核心基础搭建 | **预计时间：** 30-40 分钟

---

## 本章目标

- 创建 `i18n.js`，存储英语（en）和斯洛伐克语（sk）的翻译字典
- 实现 `t(key)` 函数，根据当前 URL 路径自动选择语言
- URL 路径规则：`/` 为英语，`/sk/` 为斯洛伐克语
- 实现 `translatePage()` 自动更新所有带 `data-i18n` 属性的 DOM 元素
- 在 `DOMContentLoaded` 时自动执行翻译

---

## 需要创建/修改的文件

| 操作 | 文件 | 说明 |
|------|------|------|
| **新建** | `assets/js/i18n.js` | 翻译字典 + 翻译函数 |
| 修改 | `index.html` | 给需要翻译的元素添加 `data-i18n` 属性 |
| 修改 | `assets/js/modal-manager.js` | 模态切换时重新翻译（可选） |

## 1. 核心代码：`assets/js/i18n.js`

```javascript
/**
 * i18n.js — 多语言国际化支持
 *
 * 语言路由规则：
 *   /        → English (en)
 *   /sk/     → Slovenčina (sk)
 *   /sk/*    → Slovenčina (sk)
 *
 * 用法：
 *   HTML:   <span data-i18n="hero.title">Hello</span>
 *   JS:     i18n.t('hero.title')  // 返回对应语言的翻译
 *   JS:     i18n.translatePage()  // 更新页面上所有 [data-i18n] 元素
 */

const i18n = (function () {
  'use strict';

  // =========================================================================
  //  翻译字典 (Translation Dictionary)
  // =========================================================================

  const translations = {

    // —————————— 英语 (English) ——————————
    en: {

      // 导航
      'nav.tech':      'Tech Stack',
      'nav.about':     'About Me',
      'nav.cv':        'CV',
      'nav.projects':  'Projects',
      'nav.contact':   'Contact',
      'nav.memo':      'Memo',
      'nav.map':       'Map',
      'nav.underhood': 'Under the Hood',

      // 模态标题
      'modal.tech.title':      'Technology Stack',
      'modal.about.title':     'About Me',
      'modal.cv.title':        'Curriculum Vitae',
      'modal.projects.title':  'Projects',
      'modal.contact.title':   'Get in Touch',
      'modal.memo.title':      'Memo',
      'modal.map.title':       'World Map',
      'modal.underhood.title': 'Under the Hood',

      // 交互提示
      'hint.press_e':    'Press E to enter',
      'hint.close':      'Press ESC or click outside to close',

      // 通用
      'common.loading':  'Loading...',
      'common.error':    'Something went wrong',
      'common.close':    'Close',
      'common.next':     'Next',
      'common.prev':     'Previous',
      'common.more':     'Read more',
      'common.back':     'Back',

      // Under the Hood 标签
      'hood.overview': 'Overview',
      'hood.tech':     'Tech',
      'hood.design':   'Design',
      'hood.stats':    'Stats',
    },

    // —————————— 斯洛伐克语 (Slovak) ——————————
    sk: {

      // Navigácia
      'nav.tech':      'Technológie',
      'nav.about':     'O mne',
      'nav.cv':        'Životopis',
      'nav.projects':  'Projekty',
      'nav.contact':   'Kontakt',
      'nav.memo':      'Poznámka',
      'nav.map':       'Mapa',
      'nav.underhood': 'Pod Kapotou',

      // Titulky modálnych okien
      'modal.tech.title':      'Technologický Stack',
      'modal.about.title':     'O Mne',
      'modal.cv.title':        'Životopis',
      'modal.projects.title':  'Projekty',
      'modal.contact.title':   'Kontaktujte Ma',
      'modal.memo.title':      'Poznámka',
      'modal.map.title':       'Mapa Sveta',
      'modal.underhood.title': 'Pod Kapotou',

      // Interakčné tipy
      'hint.press_e':    'Stlač E pre vstup',
      'hint.close':      'Stlač ESC alebo klikni mimo pre zatvorenie',

      // Všeobecné
      'common.loading':  'Načítava sa...',
      'common.error':    'Niečo sa pokazilo',
      'common.close':    'Zatvoriť',
      'common.next':     'Ďalej',
      'common.prev':     'Späť',
      'common.more':     'Čítať viac',
      'common.back':     'Naspäť',

      // Pod Kapotou karty
      'hood.overview': 'Prehľad',
      'hood.tech':     'Technológie',
      'hood.design':   'Dizajn',
      'hood.stats':    'Štatistiky',
    },
  };

  // =========================================================================
  //  语言检测
  // =========================================================================

  /**
   * 从 URL 路径检测当前语言
   * @returns {string} 'en' 或 'sk'
   */
  function detectLanguage() {
    const path = window.location.pathname;

    // 匹配 /sk/ 或 /sk 路径
    if (/^\/sk(\/|$)/.test(path)) {
      return 'sk';
    }

    // 默认英语
    return 'en';
  }

  let currentLang = detectLanguage();

  // =========================================================================
  //  公开 API
  // =========================================================================

  /**
   * 翻译单个 key
   * @param {string} key — 翻译键，如 'nav.tech'
   * @param {object} [params] — 可选插值参数，如 { name: 'John' }
   * @returns {string} 翻译后的文字；如果 key 不存在，返回 key 本身
   *
   * 示例：
   *   i18n.t('nav.tech')                     // → 'Tech Stack' (en)
   *   i18n.t('nav.tech')                     // → 'Technológie' (sk)
   *   i18n.t('greeting', { name: 'Tom' })    // 支持插值（如果字典有 "Hello, {{name}}!"）
   */
  function t(key, params) {
    const dict = translations[currentLang];
    let text = dict[key];

    // 如果找不到翻译，回退到英语
    if (text === undefined && currentLang !== 'en') {
      text = translations.en[key];
    }

    // 如果彻底找不到，返回 key 本身（方便调试）
    if (text === undefined) {
      console.warn('[i18n] Missing translation for key:', key);
      return key;
    }

    // 插值替换：将 {{variable}} 替换为 params 中的值
    if (params) {
      text = text.replace(/\{\{(\w+)\}\}/g, (match, paramName) => {
        return params[paramName] !== undefined ? params[paramName] : match;
      });
    }

    return text;
  }

  /**
   * 翻译整个页面上所有带 [data-i18n] 属性的元素
   *
   * 支持两种模式：
   *   1. 文本内容替换：<span data-i18n="key">默认文字</span>
   *   2. 属性替换：<input data-i18n-placeholder="key" placeholder="默认">
   *      支持 data-i18n-title、data-i18n-placeholder、data-i18n-alt
   */
  function translatePage() {
    // 1. 文本内容替换
    const elements = document.querySelectorAll('[data-i18n]');
    elements.forEach(el => {
      const key = el.getAttribute('data-i18n');
      if (key) {
        el.textContent = t(key);
      }
    });

    // 2. placeholder 属性替换
    const placeholders = document.querySelectorAll('[data-i18n-placeholder]');
    placeholders.forEach(el => {
      const key = el.getAttribute('data-i18n-placeholder');
      if (key) {
        el.setAttribute('placeholder', t(key));
      }
    });

    // 3. title 属性替换
    const titles = document.querySelectorAll('[data-i18n-title]');
    titles.forEach(el => {
      const key = el.getAttribute('data-i18n-title');
      if (key) {
        el.setAttribute('title', t(key));
      }
    });

    // 4. alt 属性替换（图片）
    const alts = document.querySelectorAll('[data-i18n-alt]');
    alts.forEach(el => {
      const key = el.getAttribute('data-i18n-alt');
      if (key) {
        el.setAttribute('alt', t(key));
      }
    });

    // 5. 设置 HTML lang 属性
    document.documentElement.setAttribute('lang', currentLang);

    console.log('[i18n] Page translated to:', currentLang);
  }

  /**
   * 手动切换语言
   * @param {string} lang — 'en' 或 'sk'
   */
  function setLanguage(lang) {
    if (!translations[lang]) {
      console.error('[i18n] Unknown language:', lang);
      return;
    }
    currentLang = lang;
    translatePage();
  }

  /**
   * 获取当前语言
   * @returns {string}
   */
  function getLanguage() {
    return currentLang;
  }

  /**
   * 获取当前语言的翻译字典（用于动态内容的批量查询）
   * @returns {object}
   */
  function getDictionary() {
    return translations[currentLang];
  }

  // =========================================================================
  //  自动初始化
  // =========================================================================

  /**
   * DOMContentLoaded 时自动翻译页面
   */
  function init() {
    translatePage();
    console.log('[i18n] Initialized. Language:', currentLang);
  }

  // 页面加载完成后执行翻译
  if (document.readyState === 'loading') {
    document.addEventListener('DOMContentLoaded', init);
  } else {
    // DOM 已加载（脚本在 body 底部时）
    init();
  }

  // =========================================================================
  //  导出
  // =========================================================================

  return {
    t,
    translatePage,
    setLanguage,
    getLanguage,
    getDictionary,
  };

})();

// 挂到全局方便控制台调试
window.i18n = i18n;
```

## 3. 修改交互提示 — 使用 `i18n.t()`

在 `game.js` 的 `_showHint()` 中改用翻译函数：

```javascript
// ===== game.js 中的修改 =====

_showHint(labelKey) {
  // 使用 i18n 翻译
  const translatedLabel = window.i18n ? window.i18n.t(labelKey) : labelKey;
  const prefix = window.i18n ? window.i18n.t('hint.press_e') : 'Press E to enter';

  this.hintText.textContent = prefix + ': ' + translatedLabel;
  this.hintText.style.display = 'block';
  this.hintText.style.opacity = '0';
  this.hintText.style.transition = 'opacity 0.2s ease';
  requestAnimationFrame(() => {
    this.hintText.style.opacity = '1';
  });
}
```

## 5. 部署：多语言路由配置

要让 `/` 和 `/sk/` 指向同一个站点的不同语言版本，需要服务器配置。

### Netlify (`_redirects` 或 `netlify.toml`)

```
# _redirects (放在项目根目录)
/sk/*  /index.html  200
/*     /index.html  200
```

### Vercel (`vercel.json`)

```json
{
  "rewrites": [
    { "source": "/sk/:path*", "destination": "/index.html" },
    { "source": "/:path*", "destination": "/index.html" }
  ]
}
```

两种情况下，`index.html` 中的 i18n.js 都会通过 `window.location.pathname` 检测语言。

## 6. 添加新翻译

当需要新增翻译文本时，只需：

1. 在 `i18n.js` 的 `translations.en` 中添加新的 key-value
2. 在 `translations.sk` 中添加对应的斯洛伐克语翻译
3. 在 HTML 中使用 `<span data-i18n="新key">默认英文</span>`
4. JS 中使用 `i18n.t('新key')`

```javascript
// 示例：添加新的翻译键
en: {
  // ...
  'project.card1.title': 'Portfolio Website',
  'project.card1.desc': 'A pixel RPG style portfolio built with Phaser 3.',
},
sk: {
  // ...
  'project.card1.title': 'Portfólio Webstránka',
  'project.card1.desc': 'Pixel RPG štýl portfólia postavené na Phaser 3.',
},
```

## 8. 常见坑点

| 问题 | 原因 | 解决方法 |
|------|------|----------|
| 翻译不生效 | `i18n.js` 加载时机早于 DOM 元素 | 确保在 `DOMContentLoaded` 后执行；或将脚本放在 `</body>` 前 |
| `/sk/` 路径返回 404 | 服务器不处理 SPA 路由 | 配置 URL 重写规则，将所有请求指向 `index.html` |
| 斯洛伐克语特殊字符乱码 | 文件编码不是 UTF-8 | 确保所有 `.html` 和 `.js` 文件以 UTF-8 编码保存；HTML 中加 `<meta charset="UTF-8">` |
| 模态中的文字未翻译 | 模态内容在 i18n 初始化后动态添加 | 在模态的 `open()` 中调用 `i18n.translatePage()` |
| `data-i18n` 元素闪烁原始文字 | 页面先显示英文，然后 JS 替换成目标语言 | 给 `<html>` 添加 `visibility: hidden`，翻译完成后移除（或使用 CSS 过渡） |
| 交互提示始终显示英文 | `game.js` 中硬编码了提示文字 | 确保使用 `i18n.t('hint.press_e')` 而非直接写字符串 |
| 控制台大量 Missing translation 警告 | 翻译字典中缺少某些 key | 检查是否所有 `data-i18n` 值都在 `translations` 中定义 |

## 9. 防闪烁技巧

防止翻译文本闪烁（先显示原始 HTML 文本，再被 JS 替换）：

```css
/* 在 <head> 中的一个内联脚本 */
<script>
  // 在页面渲染前设置语言 class
  (function() {
    var lang = /^\/sk(\/|$)/.test(window.location.pathname) ? 'sk' : 'en';
    document.documentElement.className = 'lang-' + lang;
  })();
</script>
```

```css
/* 初始隐藏所有待翻译元素 */
html:not(.lang-en):not(.lang-sk) [data-i18n] {
  visibility: hidden;
}

/* 语言确认后再显示 */
html.lang-en [data-i18n],
html.lang-sk [data-i18n] {
  visibility: visible;
}
```

## 章节小结

- **翻译字典** 以 `en` 和 `sk` 两个大对象组织，key 使用点号命名空间
- **语言检测** 通过 `URL pathname` 自动完成，无需用户手动选择
- **`t(key)`** 函数支持回退（sk找不到时→en→key本身）和插值参数
- **`translatePage()`** 自动遍历 DOM，支持 `data-i18n`、`data-i18n-placeholder`、`data-i18n-title`、`data-i18n-alt`
- **路由配置** 需要服务器端支持 SPA 重写规则
