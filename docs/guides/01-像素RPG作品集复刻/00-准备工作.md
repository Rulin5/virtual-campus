# 第 0 章：准备工作

> **本章目标**：装好所有需要的工具，下载好所有资源文件，确保能开始写代码。
>
> **预计时间**：1-2 小时

---

## 0.1 你需要安装的工具

### 1) Visual Studio Code（写代码用）

去 https://code.visualstudio.com/ 下载并安装。

安装后，打开 VS Code，安装以下插件（点击左侧 Extensions 图标，搜索并 Install）：
- **Live Server**（右键 HTML 文件一键在浏览器打开，自动刷新）
- **Prettier**（代码自动格式化）

**为什么用 Live Server？** Phaser 需要通过 HTTP 服务器访问（不能直接双击 HTML 文件打开），因为加载 JSON 文件需要 HTTP 协议。Live Server 插件提供了这个 HTTP 服务器。

### 2) Git Bash（命令行工具）

去 https://git-scm.com/download/win 下载并安装。
安装时全部默认选项即可。

**验证安装**：按 `Win+R`，输入 `bash`，回车，出现命令行窗口就是成功了。

### 3) 浏览器 DevTools

本教程使用 Chrome。打开 Chrome，按 `F12` 打开开发者工具。
- **Console 标签**：看日志和错误
- **Network 标签**：看资源加载情况
- **Elements 标签**：看 HTML 结构

## 0.2 项目文件夹结构

在任意位置创建项目文件夹。本教程假设放在 `peteroravec-replica/`。

```
peteroravec-replica/
├── index.html              # 主入口（唯一 HTML 文件）
├── assets/
│   ├── js/                 # 所有 JavaScript 文件
│   │   ├── phaser.min.js   # Phaser 3 游戏引擎（约 1MB）
│   │   ├── game.js         # 游戏主逻辑
│   │   ├── player.js       # 玩家角色
│   │   ├── npc.js          # NPC 系统
│   │   ├── chunk-manager.js# 地图分块管理
│   │   ├── modal-manager.js# 模态窗口管理
│   │   ├── virtual-joystick.js # 虚拟摇杆
│   │   ├── pathfinding-worker.js # 寻路 Worker
│   │   ├── i18n.js         # 多语言
│   │   └── main.js         # 入口文件
│   ├── css/
│   │   └── styles.css      # 自定义样式
│   ├── images/
│   │   ├── favicon/        # 网站图标（19 个文件）
│   │   ├── logos/          # 技术 Logo 和公司 Logo
│   │   ├── cards/          # Memo 卡片素材
│   │   └── ui/             # UI 元素
│   └── maps/               # 游戏地图数据
│       ├── final_map.json  # 主地图
│       ├── walls-layer.json
│       ├── footsteps-layer.json
│       ├── exterior.png
│       ├── collisions-objects.png
│       └── big-map.webp
└── docs/                   # 文档
```

如果 `assets/` 目录下还没有图片资源，运行以下命令创建目录并下载 Phaser：

```bash
mkdir -p assets/images/favicon assets/images/logos assets/images/cards assets/images/ui
mkdir -p assets/maps assets/js assets/css

# 下载 Phaser 3
curl -L "https://cdn.jsdelivr.net/npm/phaser@3.60.0/dist/phaser.min.js" -o assets/js/phaser.min.js
```

## 0.3 开发流程

1. 用 VS Code 打开项目文件夹：`File → Open Folder → 选 peteroravec-replica`
2. 右键 `index.html` → `Open with Live Server`
3. 浏览器自动打开 `http://127.0.0.1:5500/`
4. 每次修改代码保存（`Ctrl+S`），浏览器自动刷新
5. 按 `F12` 打开开发者工具查看 Console 是否有报错

> ⚠️ **重要**：Phaser 必须通过 HTTP 服务器访问（不能直接双击 HTML 打开）。Live Server 提供这个 HTTP 服务器。如果直接双击 index.html，Phaser 会报跨域错误，无法加载 JSON 和图片。

## 0.4 你需要知道的基础知识

本教程假设你了解以下内容（不会也没关系，每一步都有代码可以复制）：

### HTML 基础

```html
<!-- div：一个"盒子"，用来装内容 -->
<div id="my-box" class="some-style">
  这是盒子里的内容
</div>

<!-- 给元素起 id（唯一标识）和 class（样式分类） -->
```

### CSS 基础

```css
/* 选择 id=my-box 的元素，设置样式 */
#my-box {
  width: 100px;
  height: 100px;
  background: red;
}

/* 选择 class=some-style 的元素 */
.some-style {
  font-size: 16px;
}
```

### JavaScript 基础

```javascript
// 变量
let name = "张三";

// 函数
function sayHello(name) {
  console.log("你好, " + name);
}

// 获取页面元素
const box = document.getElementById("my-box");

// 监听事件
box.addEventListener("click", function() {
  console.log("被点击了!");
});
```
