> **本章目标**：写出 `index.html` 的完整 HTML 结构。此时网站还"不好看"，但所有的元素都在了——就像盖房子先把框架搭好。

## 1.2 三层结构

整个网站的 HTML 分为三个大层，用"三明治"来理解：

```
┌─────────────────────────────┐
│  第 1 层：预加载器 + Play   │  ← 游戏开始前显示
│  (Loading 动画 → Play按钮)  │
├─────────────────────────────┤
│                             │
│  第 2 层：游戏层            │  ← 游戏运行时显示
│  (Canvas + 10个模态窗口)    │
│                             │
├─────────────────────────────┤
│  第 3 层：横屏提示          │  ← 手机竖屏时覆盖最上面
│  (旋转设备提示)             │
└─────────────────────────────┘
```

---

## 1.3 每个模态窗口的结构

10 个模态窗口虽然内容不同，但外壳结构完全相同。理解这一个结构，10 个都能看懂：

```html
<div id="modal-xxx" class="modal">        ← 最外层，控制显示/隐藏
  <section>
    <div class="frame-wrp">               ← 滚动容器（内容太长时可以滚动）
      <div class="frame-wrp-inner">
        <button class="close-btn">×</button>     ← 关闭按钮
        <div class="frame pixel-corners">        ← 像素边框窗口
          <div class="text-content">             ← 内容区域
            <!-- 这里放具体内容 →
          </div>
        </div>
      </div>
    </div>
  </section>
</div>
```

## 1.5 验证方法

1. 在 VS Code 中右键 `index.html` → `Open with Live Server`
2. 浏览器打开后，应该看到白色背景 + "Loading..." 文字
3. 按 `F12` → Console 标签，可能有一些 404 错误（图片/JS 文件还没创建），这是正常的
4. 按 `F12` → Elements 标签，在 DOM 树中检查：
   - `#init-load` — Loading 覆盖层存在
   - `#preloader-screen` — 预加载器存在
   - `#play-box` — Play 界面存在（但设置了 `display:none`）
   - `#modal-tech`, `#modal-about`, `#modal-cv` 等 — 所有模态存在
   - `#game-div` — 游戏画布容器存在

## 1.6 常见踩坑

**Q：打开页面一片空白？**
A：检查 Live Server 是否启动（VS Code 右下角有端口号）。检查文件名是否确实是 `index.html`（不是 `Index.html` 或 `index.htm`）。

**Q：NES 图标不显示？**
A：检查 NES.css CDN URL 是否能访问。国内可能被墙，可换成国内 CDN 镜像。

**Q：Script 标签加载顺序重要吗？**
A：**非常重要。** phaser.min.js 必须在所有游戏 JS 文件之前加载。main.js 必须在最后加载（因为它依赖前面的所有模块）。顺序错了会导致 `is not defined` 错误。
