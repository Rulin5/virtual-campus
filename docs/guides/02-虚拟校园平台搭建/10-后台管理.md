# Phase 2 第 10 章：后台管理系统

> **本章目标**：用 React + Ant Design Pro 搭建后台，实现校园/NPC/任务/新闻的 CRUD。

> **预计时间**：3-4 小时

## 10.1 后台功能清单

| 页面 | 功能 |
|------|------|
| 校园管理 | 创建/编辑校园、上传地图、设置出生点 |
| NPC 管理 | 添加 NPC、编辑对话树、设置位置和路线 |
| 任务管理 | 创建任务、设置目标与奖励 |

## 10.4 NPC 管理页示例

```tsx
// apps/admin/src/pages/NPCs.tsx
import { ProTable } from '@ant-design/pro-components';
import { Button, Modal, Form, Input, Select, InputNumber } from 'antd';

export default function NPCs() {
  const columns = [
    { title: 'ID', dataIndex: 'id', key: 'id' },
    { title: '名称', dataIndex: 'name', key: 'name' },
    { title: '所属地图', dataIndex: 'mapId', key: 'mapId' },
    { title: '交互类型', dataIndex: 'interactionType', key: 'interactionType' },
    {
      title: '操作',
      render: (_, record) => (
        <>
          <Button type="link" onClick={() => handleEdit(record)}>编辑</Button>
          <Button type="link" danger onClick={() => handleDelete(record.id)}>删除</Button>
        </>
      ),
    },
  ];

  const handleEdit = (npc) => {
    Modal.info({
      title: '编辑 NPC',
      content: (
        <Form>
          <Form.Item label="名称"><Input defaultValue={npc.name} /></Form.Item>
          <Form.Item label="X 坐标"><InputNumber defaultValue={npc.x} /></Form.Item>
          <Form.Item label="Y 坐标"><InputNumber defaultValue={npc.y} /></Form.Item>
          <Form.Item label="交互类型">
            <Select defaultValue={npc.interactionType}>
              <Select.Option value="dialogue">对话</Select.Option>
              <Select.Option value="shop">商店</Select.Option>
              <Select.Option value="quest">任务</Select.Option>
            </Select>
          </Form.Item>
        </Form>
      ),
    });
  };

  const handleDelete = async (id) => {
    await fetch(`/api/admin/npcs/${id}`, { method: 'DELETE' });
    // 刷新表格
  };

  return (
    <ProTable
      columns={columns}
      request={async () => {
        const res = await fetch('/api/admin/npcs');
        const data = await res.json();
        return { data: data.npcs, success: true };
      }}
      toolBarRender={() => [
        <Button type="primary" onClick={() => handleEdit({})}>添加 NPC</Button>,
      ]}
    />
  );
}
```

## 10.5 后端 Admin API（Go）

```go
// 在 cmd/main.go 添加 admin 路由组
admin := api.Group("/admin")
admin.Use(middleware.JWTAuth(), middleware.RequireAdmin())
{
    admin.GET("/npcs", handler.ListNPCs)
    admin.POST("/npcs", handler.CreateNPC)
    admin.PUT("/npcs/:id", handler.UpdateNPC)
    admin.DELETE("/npcs/:id", handler.DeleteNPC)

    admin.GET("/quests", handler.ListQuests)
    admin.POST("/quests", handler.CreateQuest)

    admin.GET("/news", handler.ListNews)
    admin.POST("/news", handler.CreateNews)
}
```
