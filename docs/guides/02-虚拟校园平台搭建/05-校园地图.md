> **本章目标**：使用 Tiled Map Editor 制作校园像素地图，配合 AI 素材管线，在 Phaser 中加载。

## 5.1 制作流程

```
校园平面图 → 标记轮廓 → AI 生成像素素材 → Tiled 组装 → 导出 JSON → Phaser 加载
```

## 5.2 Tiled Map Editor 操作步骤

### 1) 新建地图

File → New → New Map：
- Map size: 100×80 tiles
- Tile size: 32×32 px
- 保存为 `campus_main.tmx`

### 2) 新建/导入瓦片集

Map → New Tileset → 选择你的 PNG 瓦片集图片 → Tile size 32×32

### 3) 创建图层（从下到上）

| 图层名 | 类型 | 作用 |
|--------|------|------|
| ground | Tile Layer | 草地、道路、水面 |
| buildings | Tile Layer | 教学楼、图书馆等 |
| decorations | Tile Layer | 树木、路灯、长椅 |
| collisions | Tile Layer | 碰撞检测数据 |
| portals | Object Layer | 建筑入口（传送点） |
| npcs | Object Layer | NPC 出生点 |
| triggers | Object Layer | 事件触发区 |

### 4) 绘制地图

选中图层 → 选中瓦片 → 点击地图放置

### 5) 放置对象

选中 Object Layer → Insert Rectangle → 拖动 → 在 Properties 设置属性

传送点属性示例：
```
Name: library_entrance
Type: portal
Custom Properties:
  targetMap = "library"
  targetX = 200
  targetY = 300
```

### 6) 导出

File → Export As → JSON → `campus_main.json`

## 5.3 AI 像素素材管线

```
需求描述 → AI 生成 → 去背景(rembg) → Python 批处理 → 人工审核 → 导入
```

### AI 提示词模板
```
pixel art {物体名}, top-down view, 32x32 pixels,
16-bit retro game style, limited 16-color palette,
clean edges, transparent background
```

### Python 批处理脚本（`scripts/process_tiles.py`）：

```python
from PIL import Image
import os

INPUT = "raw_assets/"
OUTPUT = "processed_assets/"
SIZE = 32

os.makedirs(OUTPUT, exist_ok=True)

for f in os.listdir(INPUT):
    if not f.endswith(('.png', '.jpg', '.webp')): continue
    img = Image.open(INPUT + f).convert("RGBA")
    img = img.resize((SIZE, SIZE), Image.NEAREST)
    img = img.quantize(colors=16).convert("RGBA")
    img.save(OUTPUT + f)
    print(f"✅ {f}")
```

## 5.4 在 Phaser 中加载 Tiled 地图

```javascript
// game.js preload()
this.load.tilemapTiledJSON('campus-map', 'assets/maps/campus_main.json');
this.load.image('campus-tiles', 'assets/maps/campus_tileset.png');

// game.js create()
const map = this.make.tilemap({ key: 'campus-map' });
const tileset = map.addTilesetImage('campus_tileset', 'campus-tiles');

const ground = map.createLayer('ground', tileset, 0, 0);
const buildings = map.createLayer('buildings', tileset, 0, 0);
const collision = map.createLayer('collisions', tileset, 0, 0);
collision.setCollisionByExclusion([-1]);

// 碰撞检测
this.physics.add.collider(this.player.sprite, collision);

// 读取传送点
const portals = map.getObjectLayer('portals');
portals.objects.forEach(obj => {
  this.interactionZones.push({
    x: obj.x, y: obj.y,
    width: obj.width, height: obj.height,
    modalId: obj.properties?.find(p => p.name === 'targetMap')?.value,
    label: obj.name
  });
});
```
