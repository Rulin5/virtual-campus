# Phase 2 第 0 章：准备工作 — 安装后端开发环境

> **本章目标**：安装虚拟校园平台需要的所有后端工具。
>
> **预计时间**：1-2 小时

---

## 0.1 安装清单

| 工具 | 用途 | 下载地址 |
|------|------|---------|
| Docker Desktop | 一键启动 PostgreSQL/Redis/MinIO | https://www.docker.com/products/docker-desktop/ |
| Go 1.22+ | 后端 API 服务 | https://go.dev/dl/ |
| Node.js 18+ | 前端（Phase 1 已有则跳过） | https://nodejs.org/ |
| pnpm | 高效的包管理器 | `npm install -g pnpm` |
| Tiled Map Editor | 制作游戏地图 | https://www.mapeditor.org/ |

---

## 0.2 验证每项安装

```bash
# Docker
docker --version          # Docker version 24.x.x
docker compose version    # Docker Compose version v2.x.x

# Go
go version                # go version go1.22.x windows/amd64

# Node.js + pnpm
node --version            # v18.x.x 或更高
pnpm --version            # 8.x.x 或更高

# Tiled
# 双击 Tiled 桌面图标，确认能启动
```
